# Mood Tracker PWA

## Overview
A Progressive Web App for daily mood tracking and journaling.

## Features
- Two-level mood selection
- Daily mood logging
- Interactive calendar visualization
- Persistent storage using localStorage

## Setup Instructions

### Prerequisites
- Node.js (v16 or later)
- npm (v8 or later)

### Installation
1. Clone the repository
2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm start
```

4. Build for production
```bash
npm run build
```

## Technology Stack
- React
- React Router
- Tailwind CSS
- date-fns

## Mood Categories
- Positive Moods: Happy, Excited, Calm, Grateful
- Negative Moods: Sad, Angry, Anxious, Frustrated
- Neutral Moods: Tired, Okay, Indifferent, Contemplative
